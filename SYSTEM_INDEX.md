## 1. AI Quant Lab v1.0 Overview

AI Quant Lab is a governed institutional system that moves quantitative ideas from observable market context through evidence, independent challenge, bounded authority, controlled deployment, continuous monitoring, response and learning. This index is the primary entry point. It locates documents and paths; it grants no authority.

## 2. What This Repository Is

It is the constitutional architecture, operating system and institutional memory framework for autonomous quantitative research. It defines agents, communications, shared state, evidence, workflows, registries, lifecycle gates, research disciplines, Validation, risk, decisions, portfolio construction, readiness, deployment, monitoring, incident response and learning.

## 3. What This Repository Is Not

It is not a strategy, signal service, backtest engine, optimizer, broker, execution venue, database, API, prompt collection or automatic deployment authority. Documents specify governance and required evidence; they do not prove performance or grant permissions beyond their declared role.

## 4. How To Read This Repository

Start with this index and `architecture/SYSTEM_NAVIGATION_MAP_v1.md`; then read Foundation and Master System Design, protocols/registries, the relevant agent contract, CM/IOP, and only then the domain path being used. Read upstream evidence standards before downstream verdict packages. Always follow exact versions and current status.

**High-level map:** Foundation → Master System Design → Agent Contracts → MACP / SMI / EES / WOE → Registries → Data Quality → Market Discovery → Regime Classification → Feature Factory → Edge Discovery → Strategy Family Selection → Strategy Architecture → Engineering → Implementation Parity → Experiment Design → Walk-Forward → Monte Carlo Stress → Parameter Stability → Overfitting Defense → Experiment Evidence Package → Validation Evidence Package → Risk Review Package → Portfolio Construction where applicable → Executive Decision Package → Production Readiness → Deployment Governance → Monitoring and Edge Decay → Edge Decay Response → Institutional Operations → Learning Loop.

## 5. Constitutional Core Documents

Foundation establishes institutional purpose and invariants. Master System Design defines system structure. Quant Intelligence, Knowledge, Decision and Scientific Research Operating Systems define domain-wide reasoning and governance. Agent Contract Framework defines agent constitutional form. MACP, SMI, EES and WOE govern communication, state, evidence and work. AR and ART govern actors and products.

## 6. Institutional Operating Documents

CM governs every institutional instruction. IOP governs daily cycles, queues, gates, incidents, cadences and learning. ARP governs the end-to-end research pipeline. SLS governs each strategy's state. This index and the navigation map connect them without replacing them.

## 7. Agent Contracts

Market Research Agent owns objective discovery; Research Librarian owns external acquisition/provenance; Knowledge Curator owns institutional knowledge acceptance/conflict; Quant Strategy Architect owns hypothesis-to-architecture translation; Quant Strategy Engineer owns faithful implementation; Experiment Orchestrator owns design/execution coordination; Validation Agent owns independent scientific verdict; Risk Governance Agent owns risk assessment; Executive Decision Agent owns final institutional decision. AR determines current status and rights.

## 8. Architecture Standards

Core standards are DQS, MDRS, RCS, FFS, EDS, SFSS, SLS, XDS, WFRS, MCSTS, PSS, ODS, IPS, PCS, DGS, MEDS, EDRP and PRC. Each governs one responsibility and cannot replace adjacent gates.

## 9. Evidence Packages

EEP freezes experimental design linkage, exact versions, data, configuration, results, controls, failures, robustness, deviations, limitations and reproducibility. EES governs custody and admissibility. Evidence remains evidence until an authorized independent reviewer issues the applicable verdict.

## 10. Validation, Risk, and Decision Packages

VEP determines scientific admissibility and supported scope. RRP determines risk acceptability, limits and controls without broadening VEP. EDP determines institutional lifecycle authority without rewriting VEP or RRP. Their sequence and boundaries are mandatory.

## 11. Deployment and Monitoring Documents

PRC classifies stage-specific readiness but cannot activate. DGS verifies and controls deployment state within EDP scope. MEDS governs baselines, health, drift, breaches and monitoring evidence. EDRP governs containment, returns, revalidation, reactivation and retirement after deterioration.

## 12. Robustness and Overfitting Documents

WFRS governs temporal/out-of-sample robustness; MCSTS governs stochastic and adversarial stress; PSS governs neighborhoods, islands, cliffs and interactions; ODS governs leakage, multiple testing, holdout exposure, complexity, PBO, metric deflation and negative controls. None validates by itself.

## 13. Data, Implementation, and Portfolio Documents

DQS governs identity, lineage, temporal integrity, preprocessing, defects and eligibility. IPS proves event-level behavioral equivalence across architecture, Python/Pine, paper/live, controls and monitoring. PCS governs component eligibility, allocation scope, risk budgets, exposures, dependence, liquidity/capacity, constraints and stress.

## 14. Command and Operations Documents

CM turns intent into identity-, authority-, scope- and evidence-bound commands. IOP runs daily command/workflow/evidence/artifact/memory/monitoring/incident queues and learning cadences. Neither overrides domain standards or approval authorities.

## 15. Master Strategy Lifecycle Path

Proposed → Researching → Hypothesis Defined → Architecture Drafted/Approved → Implementation Drafted/Verified → Experiment Planned/Executed → Evidence Packaged → Validation Review/Passed → Risk Review/Approved → Executive Decision → Deployment Candidate → Paper Monitoring → Limited Live → Live Active → Degraded/Suspended → Reactivated or Retired → Archived. Only SLS and authorized packages determine exact transitions.

## 17. Master Failure-to-Learning Path

Failure is never deletion. Research failure, market rejection, regime uncertainty, feature/edge/family/architecture rejection, engineering/IPS/experiment/robustness/PSS/ODS/DQS failure, VEP/RRP/PCS/EDP rejection, PRC/DGS/MEDS failure, decay, emergency containment and retirement all route to evidence freeze, ART preservation, reason classification, owner assignment, impact scope, possible return or retirement, learning update and audit. Failed scope cannot silently re-enter under a new name.

## 18. Master Emergency Path

Monitoring signal or incident → EDRP trigger classification → evidence freeze → severity → authority identification → risk-reducing action → communication → escalation → post-action monitoring → review path → VEP/RRP/EDP/retirement where applicable. Containment may reduce risk before full review; it cannot create authority, silently retune, silently reactivate or escape audit.

## 22. Authority Boundary Map

Research proposes but does not validate. Engineering implements but does not change hypothesis. Experimentation produces evidence but does not approve. Validation approves evidence scope but not risk. Risk approves bounded limits but not Executive deployment authority. Executive decides but cannot rewrite evidence. PCS classifies portfolio eligibility but grants neither risk nor deployment approval. PRC classifies readiness but does not deploy. DGS activates only within EDP/PRC scope. Monitoring observes/escalates but cannot silently retune. EDRP contains, suspends, routes and recommends but cannot validate, accept risk or create deployment authority. CM routes but cannot override standards. IOP runs cycles but cannot override gates.

## 24. Operator Quick Start

Read CM, IOP, WOE, AR, MACP/SMI/EES/ART first. Issue a governance-style command stating intent, scope, authority, owner, evidence and expected output. Check queues, blockers, versions, custody and deadlines. Do not assume status equals approval. Expect a Command Record, WOE workflow, assigned agent and auditable output/handoff.

## 25. Reviewer Quick Start

Read EES, ART, WOE, relevant package standard and IOP. Request review of exact object/version/scope with provenance and criteria. Check freeze, lineage, completeness, contradictions, limitations and independence. Do not infer missing evidence. Expect accepted/rejected/qualified evidence, findings, conditions and audit references.

## 26. Executive Quick Start

Read Decision OS, EDP, VEP, RRP, PCS, PRC and DGS. Issue an Executive Decision request citing exact versions, target stage and open issues. Check that VEP/RRP scopes align and conditions are enforceable. Do not treat performance or readiness as authority. Expect an EDP verdict with scope, conditions, monitoring, expiry and return path.

## 27. Researcher Quick Start

Read Scientific Research OS, ARP, DQS, MDRS/RCS/FFS/EDS/SFSS and XDS. Issue a research command with falsifiable question, context, scope, data and expected artifact. Check prior evidence, controls, uncertainty and selection history. Do not design indicators before mechanism or claim edge from backtest. Expect registered research artifacts and an explicit handoff/return/rejection.

## 28. Engineer Quick Start

Read agent contract, approved architecture, ART, DQS, FFS/RCS, IPS and XDS. Issue/accept an Engineering command for exact versions and reference behavior. Check fidelity, platform assumptions, timing, costs, state and deviations. Do not modify hypothesis or Validation evidence. Expect versioned implementation artifacts and parity evidence.

## 29. Validator Quick Start

Read VEP, EES, EEP, DQS, IPS, WFRS/MCSTS/PSS/ODS. Accept only a frozen scope-matched package. Check admissibility, reproducibility, leakage, robustness, controls, contradictions and limitations. Do not accept risk or approve deployment. Expect an issued VEP with verdict, scope, rationale, conditions and risk handoff.

## 30. Risk Reviewer Quick Start

Read RRP, issued VEP, PCS, MCSTS, DGS/MEDS. Issue/accept a risk-review command for exact versions/capital context. Check VEP boundaries, tails, drawdowns, execution, liquidity, portfolio interaction, controls and kill paths. Do not broaden Validation or issue Executive authority. Expect RRP verdict, limits, monitoring and handoff.

## 31. Deployment Operator Quick Start

Read EDP, PRC, DGS, DQS, IPS, RRP, MEDS and EDRP. Accept only exact authorized stage/scope/version commands. Check locks, owners, controls, kill, rollback, incident and monitoring readiness. Do not promote paper to limited live or limited live to active. Expect an authorized DGS state record or readiness failure/return.

## 32. Monitoring Operator Quick Start

Read MEDS, EDRP, DGS, RRP/EDP, PCS and IOP. Issue/accept a monitoring command for exact deployment and baseline versions. Check coverage, thresholds, alert delivery, health states, data/parity drift and open incidents. Do not interpret silence as health or retune after decay. Expect monitoring evidence, warnings/breaches and EDRP workflow where required.

## 33. Final v1.0 System Statement

AI Quant Lab v1.0 is now a governed institutional architecture for autonomous quantitative research, evidence generation, independent validation, risk review, executive decision, portfolio construction, deployment governance, monitoring, response, operations and learning.

AI Quant Lab is not a single strategy. AI Quant Lab is not a backtest engine. AI Quant Lab is not an optimizer. AI Quant Lab is not a trading signal service. AI Quant Lab is a governed institutional intelligence system for discovering, testing, challenging, validating, governing, deploying, monitoring and learning from quantitative strategies.

The index navigates; it does not govern alone. No document operates alone, no standard replaces another, no agent owns the whole system, no workflow skips evidence, no evidence becomes decision, no decision rewrites evidence, no readiness becomes deployment, no monitoring silence becomes health, no emergency expands authority, no failure becomes deletion and no archive becomes forgetting.
