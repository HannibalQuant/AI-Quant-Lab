## 21. Artifact Registry Taxonomy Reconciliation

ART now explicitly covers PSS, ODS, DQS, IPS, PCS, PRC, CM, IOP, FSI/navigation, readiness-review and integration-report artifacts. The amendment is classificatory: each domain still controls content and permitted use; ART controls identity, version, lineage, custody, lifecycle and audit.

## 22. PCS Applicability Reconciliation

PCS is mandatory for multi-strategy portfolios and whenever capital, margin, venue, liquidity, execution, correlated instruments, common features/signals/data, shared failure modes, material single-strategy portfolio impact or scaling crosses isolated scope. A non-applicable decision must be evidenced, scoped, authorized, time-bounded/reviewable and audited.

## 23. IPS Checkpoint Reconciliation

Eight distinct checkpoints are now explicit: pre-experiment reference parity, research implementation parity, post-engineering parity, pre-paper, pre-limited-live, pre-live-active, post-remediation and monitoring/control parity. Each checkpoint has its own versions, scope, tolerances, mismatches, expiry and consumers.

## 25. Evidence Flow Revalidation

DQS and source records feed research; XDS governs experiments; WFRS/MCSTS/PSS/ODS contribute bounded evidence; EEP freezes the experiment package; VEP independently validates scope; RRP accepts/rejects bounded risk; EDP decides without rewriting inputs. PCS enters where applicable. PRC/DGS/MEDS/EDRP consume but cannot replace issued upstream evidence.

## 26. Artifact Flow Revalidation

Every material output has ART identity/version/lineage and EES custody where evidentiary. Freeze, supersession, invalidation, archive and consumer references remain separate from domain verdicts. The later record-type gap is closed.

## 27. Workflow Flow Revalidation

CM intake opens WOE work; AR bounds assignees; MACP transports; SMI holds shared state; ART/EES preserve outputs/evidence. Domain workflows advance only through their own gates. WOE “Approved” never substitutes for SLS, VEP, RRP, EDP, PRC or DGS states.

## 28. Command and Operations Flow Revalidation

CM defines identity, authority, intent, scope, evidence, constraints, responsible agent, output and audit. IOP operates queues and cadences. Neither may silently waive evidence, reassign authority, close blockers or turn completion into approval.

## 29. Emergency Path Revalidation

MEDS signal/incident → EDRP classification → evidence freeze → severity → authority identification → risk-reducing containment → communication/escalation → post-action monitoring → governed review. Containment can reduce risk before full review but cannot create authority, retune silently or reactivate.

## 30. Return Path Revalidation

Returns identify trigger, competent authority, affected scope, frozen records, deficiencies, required new output and precise destination. Downstream reliance is invalidated only to the affected extent. No return permits a shortcut around the original gate.

## 31. Failure-to-Learning Path Revalidation

Failure preserves evidence and artifacts, classifies cause, assigns owner, records contradictions and limitations, opens a governed return/retirement path and updates Knowledge OS/IOP learning with provenance. Failure is never deletion.
